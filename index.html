Colab Drive Transfer

A personal desktop workflow for transferring user-selected documents between user-controlled computers and Google Drive, and retrieving document-conversion results.

What it does

The workflow uses rclone with a dedicated Google OAuth desktop client. The user signs in directly with Google. Transfers run on the user's computer; this information website does not receive documents, authorization codes or tokens.

When separately requested by the user, documents can be processed in a Google Colab runtime using a self-hosted document parser. Inputs, model caches and outputs may be stored in the user's Google Drive. Colab processing takes place in Google's cloud, not offline on the user's computer.

Why Drive permission is requested

The workflow uploads selected inputs and downloads existing results, including files created by Colab or other tools. It requests the Google Drive scope to support those operations. That permission is technically broad; operations are limited to files and folders selected or authorized by the user. The application does not automatically make files public.

Availability and support

This is an owner-operated desktop workflow, not a public document-upload service. This website provides application information for its OAuth consent screen. It does not offer a sign-in or upload form.

Read the privacy policy. For questions, contact the maintainer through the project support page. Do not post private documents, credentials or authorization codes.
